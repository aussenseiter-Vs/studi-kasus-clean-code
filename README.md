# Studi Kasus: Code Review & Clean Code Modul Pembayaran

Proyek ini adalah simulasi _Code Review_ dan _Refactoring_ dari fitur perhitungan diskon SPP.

## Skenario

Seorang developer junior mengirimkan PR untuk fitur: _"Menambahkan logika perhitungan diskon SPP sebesar 5% untuk siswa yang sudah melunasi biaya pendaftaran."_ Kode tersebut bekerja tanpa error, tetapi kualitas kodenya buruk.

## Tugas

1. Buka file `src/payment.js`.
2. Lakukan evaluasi pada kode tersebut (tulis komentar _review_).
3. Lakukan _Refactoring_ agar memenuhi kaidah _Clean Code_.
4. Pastikan kode Anda tetap lulus uji setelah diubah!

## Cara Menjalankan Tes

1. Pastikan Anda telah menginstal Node.js.
2. Buka terminal di folder ini, jalankan:
   ```bash
   npm install
   ```
